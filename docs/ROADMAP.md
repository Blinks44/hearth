# Hearth Roadmap

Hearth **v1.0.0** is feature-complete across macOS, Windows, and Linux. This roadmap tracks post-v1.0 priorities and areas where community feedback is especially welcome.

## Post-v1.0 Priorities

- **Code signing & notarization:** Apple Developer ID signing/notarization for macOS `.dmg` and Authenticode signing for Windows installers once funded or sponsored, eliminating first-launch Gatekeeper/SmartScreen warnings.
- **Package distribution:** Official Homebrew Cask submission (`homebrew-cask`), WinGet community manifest (`winget-pkgs`), and Arch AUR package maintenance alongside the existing `Blinks44/homebrew-tap` and Linux `.deb` / `install.sh` / `PKGBUILD` releases.
- **Linux desktop polish:** Expanded Wayland/KDE/distro testing, Flatpak/AppImage evaluation based on user demand.
- **WSL2 awareness on Windows:** Detecting WSL distributions, toolchains, and Docker/Kubernetes integration alongside native Windows tools.
- **Broader tool & AI ecosystem support:** Additional runtimes, container engines, and AI coding agents as the ecosystem evolves (tracked via GitHub Discussions and Issues).

Have a suggestion or want to help? Open a thread in [GitHub Discussions](https://github.com/Blinks44/hearth/discussions) or file a [Feature Request](https://github.com/Blinks44/hearth/issues/new/choose).
